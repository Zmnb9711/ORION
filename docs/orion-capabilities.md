# Возможности ORION

Страница «Возможности» отображается из главного окна лаунчера и использует структурированный каталог `GET /v1/capabilities`.

## Разделы

- Полет — запуск миссии, определение самолета, карты и коалиции, контроль состояния самолета.
- Virtual ATC — запуск, руление, взлет, заход, посадка, аварийные процедуры, русский и английский языки.
- AWACS — BRAA, Picture, Bogey Dope, Declare, оценка воздушной обстановки.
- Mission Control — анализ целей и угроз, рекомендации по маршруту, топливу и вооружению.
- Работа с союзниками — лазерное целеуказание, дымовая маркировка, JTAC/FAC, AWACS, танкер и дружественная авиация.
- Дозаправка — поиск танкера, позывной, частота, TACAN, положение и расстояние.
- Навигация — аэродромы, курс, расстояние, координаты и ETA.
- Боевая помощь — предупреждения об угрозах, рекомендации по атаке и отходу.
- Debrief — анализ выполнения задачи, ошибок и рекомендации.
- Общение — авиационный английский, авиационный русский, свободное общение и случайные разговоры.
- Mission Pack — безопасная копия миссии, резервирование, внедрение и проверка компонентов ORION.
- Flight Console — статусы, команды, сообщения, живые события и журнал.
- Диагностика — проверка компонентов ORION, микрофона, аудиовыхода и AI.

## Аудиоустройства

В разделе «Голос» пользователь отдельно выбирает:

- устройство ввода из всех доступных устройств записи Windows;
- устройство вывода из всех доступных устройств воспроизведения Windows;
- системное устройство Windows по умолчанию для любого из списков.

ORION хранит стабильный идентификатор устройства. Список обновляется по запросу пользователя без перезапуска приложения. Кнопки проверки микрофона и звука используют выбранные устройства.
